# Vendor Workflow

1. **Authentication**: Trustfabric employee logs into the Trustfabric Admin Portal (`/dashboard`).
2. **Customer Onboarding**: Vendor navigates to `/customers` to register a new Enterprise and its initial Companies.
3. **Entitlement Granting**: Vendor navigates to `/entitlements`, selects an Enterprise and a Product, and creates an Entitlement (e.g., 1000 seats).
4. **Monitoring**: Vendor monitors global consumption across all customers via `/installations` and `/audit`.
5. **Revocation**: Vendor can suspend or revoke Entitlements globally if required due to billing or compliance issues.
